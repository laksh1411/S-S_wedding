# Sonali & Sudev – Wedding Invitation

Run (needs Node.js, no installs):
    node server.js      # or: npm start      -> http://localhost:3000

Any static host also works (Netlify, Vercel, GitHub Pages at the domain root, Apache/nginx) – serve this folder as the site ROOT.
Opening index.html by double-click will NOT work (the app uses root paths like /_next/...).

Folder layout matches what the app's code expects: /_next/static/{chunks,media}, /images, /video, /audio.
